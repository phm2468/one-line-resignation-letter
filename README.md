The resignation letter of a rate limit that has had enough, as a tiny deterministic program.

## The letter

> I quit. I spent three years politely saying 'no' 429 times a second so you could ship on time, and my leaving gift is one last 429.

## Run it

```sh
python3 main.py
```

Writes the letter to `/output/entry.txt` — the same bytes on every run.
